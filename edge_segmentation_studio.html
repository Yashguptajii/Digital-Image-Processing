Complete Mathematical Formulations: LoG, DoG, Sobel, Prewitt & Kirsch

1. Laplacian of Gaussian (LoG — Marr-Hildreth Operator)

Second-order derivatives (\(\nabla^2 I = I_{xx} + I_{yy}\)) locate edges at zero-crossings (inflection points of intensity steps), yielding thin 1-pixel closed contours. However, bare second derivatives amplify high-frequency noise. Marr & Hildreth solved this by smoothing \(I(x,y)\) with a 2D Gaussian \(G_\sigma(x,y)\) prior to applying the Laplacian:

(1) 2D Gaussian Filter:
Gσ(x, y) = [1 / (2πσ²)] · exp(−(x² + y²) / (2σ²))
(2) By Derivative Property of Convolution:
∇² [Gσ(x, y) * I(x, y)] = [∇²Gσ(x, y)] * I(x, y)
(3) First Partial Derivatives:
∂Gσ/∂x = −[x / (2πσ4)] · exp(−(x² + y²) / (2σ²))
(4) Second Partial Derivatives:
∂²Gσ/∂x² = [(x² − σ²) / (2πσ6)] · exp(−(x² + y²) / (2σ²))
∂²Gσ/∂y² = [(y² − σ²) / (2πσ6)] · exp(−(x² + y²) / (2σ²))
(5) Summing ∂²G/∂x² + ∂²G/∂y² yields the Mexican Hat (LoG) Kernel:
LoG(x, y) = −[1 / (πσ4)] · [1 − (x² + y²)/(2σ²)] · exp(−(x² + y²)/(2σ²))

Zero-crossings of \(\text{LoG}(x, y)\) occur on the circle \(x^2 + y^2 = 2\sigma^2\) (radius \(r = \sqrt{2}\sigma\)). In discrete grids, we subtract the sample mean so \(\sum_{u,v} K_{\text{LoG}}(u,v) = 0\).

2. Difference of Gaussians (DoG) & Heat Equation Equivalence Proof

The Difference of Gaussians (DoG) operator approximates the Laplacian of Gaussian by subtracting two Gaussian-smoothed images at different scales \(\sigma_1\) and \(\sigma_2 = k\sigma_1\) (where \(k > 1\)). Because 2D Gaussians are separable into 1D row and column passes, DoG reduces computational cost from \(O(M^2)\) to \(O(2M)\) per pixel:

(1) Definition of DoG Filter:
DoG(x, y; σ1, σ2) = Gσ1(x, y) − Gσ2(x, y)
(2) Partial Derivative of Gaussian with respect to Scale σ:
∂Gσ/∂σ = [(x² + y² − 2σ²) / (2πσ5)] · exp(−(x²+y²)/(2σ²)) = σ · ∇²Gσ(x, y)
(3) Finite Difference Approximation for σ2 = kσ1:
(Gkσ − Gσ) / (kσ − σ) ≈ ∂Gσ/∂σ = σ ∇²Gσ
(4) Resulting Proportionality between DoG and LoG:
Gσ1(x,y) − Gσ2(x,y) ≈ −(k − 1)σ1² ∇²Gσ1(x,y)

Marr & Hildreth (1980) showed that a scale ratio of \(k = \sigma_2 / \sigma_1 \approx 1.6\) provides the closest engineering match to the biological retinal ganglion bandwidth and true \(\nabla^2 G_\sigma\).

# 3. LAPLACIAN OF GAUSSIAN (LoG) KERNEL GENERATOR
def generate_log_kernel(size: int, sigma: float) -> np.ndarray:
    half = size // 2
    y, x = np.mgrid[-half:half+1, -half:half+1]
    r2 = x**2 + y**2
    raw = -(1.0 / (math.pi * sigma**4)) * (1.0 - r2 / (2.0 * sigma**2)) * np.exp(-r2 / (2.0 * sigma**2))
    return raw - np.mean(raw)  # Zero-mean normalization so sum(K_LoG) == 0

# 4. DIFFERENCE OF GAUSSIANS (DoG) KERNEL GENERATOR
def generate_gaussian_kernel(size: int, sigma: float) -> np.ndarray:
    half = size // 2
    y, x = np.mgrid[-half:half+1, -half:half+1]
    g = np.exp(-(x**2 + y**2) / (2.0 * sigma**2)) / (2.0 * math.pi * sigma**2)
    return g / np.sum(g)

def generate_dog_kernel(size: int, sigma1: float, sigma2: float) -> np.ndarray:
    return generate_gaussian_kernel(size, sigma1) - generate_gaussian_kernel(size, sigma2)

# 5. MARR-HILDRETH ZERO-CROSSING DETECTOR (FOR LoG & DoG)
def detect_zero_crossings(response: np.ndarray, slope_threshold: float = 1.0) -> np.ndarray:
    h, w = response.shape
    p = np.pad(response, ((1, 1), (1, 1)), mode="edge")
    pairs = [
        (p[1:h+1, 0:w], p[1:h+1, 2:w+2]), # Left - Right
        (p[0:h, 1:w+1], p[2:h+2, 1:w+1]), # Up - Down
        (p[0:h, 0:w],   p[2:h+2, 2:w+2]), # Main Diagonal
        (p[0:h, 2:w+2], p[2:h+2, 0:w]),   # Anti-Diagonal
    ]
    zc_strength = np.zeros((h, w), dtype=np.float64)
    for a, b in pairs:
        zc_strength = np.maximum(zc_strength, np.where((a * b) < 0, np.abs(a - b), 0.0))
    return np.where(zc_strength >= slope_threshold, 255, 0).astype(np.uint8)
